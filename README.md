# Scenario Generator — деплой как Worker (не Pages)

Структура:
```
public/index.html   ← сайт (генератор + живая практика)
src/index.js         ← Worker: раздаёт public/ + обрабатывает /api/scenario-ai
wrangler.toml        ← связывает их в один деплой
```

**Провайдер ИИ: OpenRouter**, модель `openrouter/free` — это
авто-роутер, который сам выбирает из бесплатных моделей на площадке
(DeepSeek, Llama, Qwen и т.д.) и ничего не берёт за токены. Карта не
нужна для регистрации и для бесплатных моделей.

## Честно про лимиты — прочитайте перед деплоем

Бесплатные модели на OpenRouter — не безлимит:
- **20 запросов в минуту**
- **50 запросов в сутки**, пока вы ни разу не пополнили баланс —
  **1000 запросов в сутки** после разового пополнения от $10
  (пополнение не сгорает, это не подписка)

Ключевой момент: **этот лимит общий на весь API-ключ**, то есть на
**всех посетителей сайта суммарно за день**, а не 50 на человека. Один
проход через живую практику с ИИ (открытие сцены + несколько реплик +
разбор в конце) может съесть 8–15 запросов сам по себе. При активном
использовании 50/день реально исчерпать за один хороший рабочий день.

Если это упрётся в лимит — сайт не «сломается» насовсем, но все
посетители будут получать ошибку до полуночи по UTC, когда лимит
сбросится. Практический вывод: если планируете использовать это не
эпизодически, а регулярно — разовое пополнение на $10 (без подписки,
без риска, что спишут больше) снимет проблему почти полностью,
подняв потолок до 1000/день.

## Качество

Бесплатные модели на OpenRouter — это открытые модели среднего
калибра (не GPT/Claude-уровня), и на русском языке качество текста и
живость персонажа в чате будут заметно проще, чем было с Claude.
Проверьте на живом сайте — если не устроит, можно закрепить конкретную
платную модель прямо через тот же ключ OpenRouter, поменяв
`SCENARIO_AI_MODEL` в `src/index.js` на, например,
`"anthropic/claude-sonnet-5"` или `"deepseek/deepseek-chat"` — один
интеграционный код работает со всеми, меняется только строка модели.

## Ключ OpenRouter

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) —
   отдельный аккаунт, не связан ни с Anthropic, ни с DeepSeek.
2. Keys → Create Key → скопируйте.
3. Карта не нужна, если остаётесь на `openrouter/free`.

Почему не Pages: Cloudflare сейчас объединяет Pages и Workers. Если
задеплоить как «чисто статику», у проекта не оказывается вычислительного
слоя — и вкладка Variables/Secrets попросту недоступна. Схема ниже —
настоящий Worker с кодом, поэтому секреты подключаются как обычно.

## Деплой через CLI (быстрее всего)

Понадобится Node.js. Из папки проекта:

```
npm install -g wrangler        # если ещё не стоит
wrangler login                 # один раз, откроет браузер для авторизации
wrangler secret put OPENROUTER_API_KEY   # вставит ключ как секрет
wrangler deploy
```

После `wrangler deploy` сайт будет доступен по адресу вида
`scenario-generator.<ваш-субдомен>.workers.dev` — бесплатно, без
покупки домена.

## Если хотите автодеплой из GitHub (как у amacademy.pro)

1. Запушьте эту папку целиком (`public/`, `src/`, `wrangler.toml`) в
   репозиторий на GitHub.
2. Cloudflare Dashboard → **Workers & Pages** → **Create** →
   **Workers** (не Pages) → **Connect to Git** → выберите репозиторий.
   Cloudflare увидит `wrangler.toml` и настроится сам.
3. Settings → **Variables and Secrets** → добавьте `OPENROUTER_API_KEY`
   как Secret.
4. Redeploy, если переменная не подхватилась сразу.

## Свой домен позже

Тот же принцип, что раньше: в настройках Worker → **Triggers** →
**Custom domains** → добавьте, например, `scenarios.amacademy.pro`.
Домен уже у вас в Cloudflare — покупать ничего не нужно.

## Лимит запросов в сутки на вашей стороне (опционально)

Это ДОПОЛНИТЕЛЬНЫЙ лимит поверх лимита OpenRouter — например, чтобы
один человек не выбрал за день весь общий дневной лимит в одиночку.

1. `wrangler kv namespace create SCENARIO_KV` — покажет `id`.
2. Впишите этот `id` в `wrangler.toml`, раскомментировав блок
   `[[kv_namespaces]]`.
3. `wrangler deploy` ещё раз.

Без этого шага лимит просто не работает — код обрабатывает отсутствие
KV-биндинга мягко, ничего не ломается.
